# Changelog

All notable changes to Peppa's Memory Game are documented here.

---

## [1.3.0] - 2026-03-01
### Added
- 🏆 Hall of Fame leaderboard — winners enter their name after finishing
- Scores saved persistently to `peppa_scores.json`
- 🥇🥈🥉 Medal rankings for top 3 on the leaderboard
- Leaderboard visible on main menu screen
- Winner's entry highlighted in pink after saving

---

## [1.2.0] - 2026-03-01
### Added
- 🌸 Easy (4 pairs), 🌟 Medium (8 pairs), 🔥 Hard (12 pairs) difficulty levels
- Difficulty selection screen between mode and game screens
- Adaptive card sizes per difficulty (bigger cards on Easy for little ones)
- 6×4 grid layout for Hard mode
- Difficulty badge shown during gameplay
- "Change Difficulty" button on win screen and bottom nav

---

## [1.1.0] - 2026-03-01
### Added
- 👥 2 Player mode with turn-based gameplay
- Mode selection screen (Single Player vs 2 Players)
- Turn indicator banner showing whose go it is
- Bonus turn rule — matching a pair earns another turn
- Player-coloured matched cards (green = P1, blue = P2)
- Per-player pair counters and winner announcement
- "Change Mode" button to return to mode selection

---

## [1.0.0] - 2026-03-01
### Added
- 🐷 Initial release — Single Player memory game
- 16 cards (8 pairs) in a 4×4 grid
- Peppa-themed emojis: 🐷🌈🌟🦋🍭🐸🎀🌸
- Move counter, match tracker, cards remaining display
- Cards flip back automatically on a mismatch
- 🎉 Win screen with balloons
- Pink Peppa-style theme with Baloo 2 font
